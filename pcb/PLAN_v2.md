## Почему так (не переигрывать без причины)
- Суммирующие узлы SUMA_HN/CN, SUMB_HN/CN (J12 → входы ОУ) — виртуальная земля, должны быть КОРОТКИМИ. Сумматор связан только с J12 и реле K16/K20, с XLR не связан. Поэтому он у J12, а не у XLR.
- CN9 = аналоговые входы A0–A5 → всё измерительное (датчики, ADC) слева от Nucleo. CN7/CN10 = цифра → драйверы и LM339 справа.
- Связи между блоками (сигнальные цепи): J1–логика 40, Nucleo–драйверы 22, драйверы–реле 21, J1–реле 18, Nucleo–LM339 13, Nucleo–J12 10, J1–J12 10, реле–XLR 8.
- Оценка HPWL: сейчас 34,5 м (Nucleo 9,2 / аудио 2,6); v2 32,0 м (Nucleo 5,3 / аудио 3,4).
- Прошлый провал: Nucleo в углу + латание готовой разводки; внешний ряд выводов выходил только вдоль края.

## Технические уроки (инструменты)
- FreeRouting 2.1.0: плато 21–40 неразведённых, CLI игнорирует -mp, падает по памяти; промежуточные результаты из API ненадёжны.
- Свой трассировщик: /home/claude/pcb/mz/route.py (A*, 3 слоя: 1 Top, 2 Bottom, 16 Inner2). Переменные: MZG (сетка, мил), MZM (запас зазора), MZWIN (окно в координатах DSN), MZKO (запретные зоны x0,y0,x1,y1 в координатах EasyEDA, через ;), MZN (лимит поиска). Сохраняет результат после каждой цепи. Порядок цепей решает всё: внешние ряды разъёмов — первыми. tojs.py → скрипт для EasyEDA; chk*.py — проверка зазоров; merge.py — добавить трассы в DSN; unr2.py — счёт неразведённых по DSN.
- EasyEDA: переходные, созданные скриптом, считаются подключёнными только после закрытия и повторного открытия вкладки платы; перед скриптовой вставкой трасс снять «Remove Loop»; полигоны пересобирать через Tools → Copper Manager → Rebuild All (Shift+B не всегда срабатывает); DSN экспорт: eda.pcb_ManufactureData.getDsnFile(); DRC: eda.pcb_Drc.check(false,false,true).
- Футпринт системной библиотеки нельзя копировать через API; зеркальный вариант делается в редакторе: открыть → Ctrl+A → Layout → Flip → File → Save as в ZABORKA_LIB; назначение — через Footprint Manager в схеме, затем Import Changes.
- Облачный контейнер иногда перезапускается: долгие расчёты запускать через nohup и сохранять промежуточные результаты.
